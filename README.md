# Customer Insights System

顧客の退会を減らしたい運営者のための「顧客離脱予測・分析システム」です。  
FastAPIで構築した退会確率予測APIと、Reactの視認性を重視した管理画面を連携させたアプリです。

---

## ️使用技術（技術スタック）

* **フロントエンド**: TypeScript / React (Vite)
* **バックエンド**: Python / FastAPI
* **データベース**: SQLite
* **インフラ**: Docker / Docker Compose / AWS EC2 / Elastic IP

---

## 開発・設計のポイント

1. **実務を意識した本番環境の構築**  
   AWS EC2上にDocker環境を構築し、24時間365日いつでもアクセス可能な状態にしています。  
   また、Elastic IPを導入してパブリックIPアドレスを固定化し、運用の安定性を高めました。

2. **Dockerによる「環境依存」の排除と再現性**  
   開発環境（ローカル）と本番環境（AWS）の差異をなくすため、コンテナによる環境の共通化を行いました。  
   「手元のPCでは動くのにサーバーでは動かない」といった環境トラブルを排除し、どこでも1コマンドで同じアプリ環境を再現できる実務的な設計を意識しました。

3. **FastAPIによる高速なAPI開発**  
   軽量で高速なFastAPIの特性を活かし、フロントエンドからのリクエストに対してスムーズに応答する予測APIを実装しました。

---

## 主要機能一覧

* **顧客一覧表示**: 大量の顧客データをページネーションでスムーズに閲覧
* **リアルタイム退会予測**: ボタン一つで顧客ごとの退会確率（%）を即座に算出
* **離脱要因の可視化**: 予測の根拠となる上位7項目（契約期間や通話料金など）の値を表示
---

## ローカル環境での起動方法

Dockerがインストールされていれば、以下のコマンドでフロント・バック・DBがすべて立ち上がります。

```bash
# 1. リポジトリのクローンと移動
git clone https://github.com/ito-biz-work/ubuntu-churn-prediction-app.git
cd ubuntu-churn-prediction-app

# 2. コンテナの起動
docker compose -f compose.prd.yaml up -d --build
```
